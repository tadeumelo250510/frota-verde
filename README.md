# FrotaVerde - Sistema de Gestão de Abastecimento e Frota

Sistema web moderno e completo para gestão de frotas, controle de abastecimentos, manutenção preventiva, motoristas/gestores e cálculo de emissões e economia de combustível.

## 🚀 Tecnologias Utilizadas

- **React 18** com **TypeScript**
- **Vite** para empacotamento rápido
- **Tailwind CSS** para estilização responsiva e limpa
- **Lucide React** para ícones do sistema
- **Recharts** para gráficos analíticos

## 📦 Funcionalidades

- **Acesso e Autenticação com Perfis**:
  - Administrador Root com permissões completas
  - Gestores de Frota e Operadores
- **Gestão de Abastecimentos**:
  - Registro de litros, quilometragem, valor por litro, odômetro e tipo de combustível
  - Histórico detalhado de abastecimentos com filtros e exportação
- **Gestão de Veículos**:
  - Cadastro completo de caminhões, vans e utilitários
  - Acompanhamento de placa, modelo, capacidade e status
- **Manutenção e Alertas**:
  - Controle de manutenções preventivas e corretivas
  - Alertas de revisão por quilometragem e data
- **Relatórios e Indicadores**:
  - Consumo médio (km/l), custo por quilômetro e gastos totais
  - Monitoramento de emissões de CO₂

## 🛠️ Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/tadeumelo250510/frota-verde.git
cd frota-verde
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Para gerar a versão de produção:
```bash
npm run build
```
